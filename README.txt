JORGE PARDO CV WEBSITE
========================

Files:
- index.html  -> page structure/content
- style.css   -> visual design/layout/responsive behavior
- script.js   -> navigation and dark mode
- images/jorge-pardo.png -> profile photo

LOCAL TEST
----------
1. Open the folder in VS Code.
2. Open index.html in a browser, or use the Live Server extension.
3. Try resizing the browser and the dark-mode button.

WIX STATIC SITE
---------------
For the Wix static-site upload option you were researching:
- Keep index.html at the root of the package.
- Keep style.css and script.js at the root.
- Keep the images folder with the image.
- Zip the contents of this folder and upload the ZIP through Wix's static-site/headless upload flow.

This is a static front-end site: HTML + CSS + JavaScript. It does not contain a backend or database.
